**Endpoint**

## Parameter Mapping: Anthropic ↔ OpenAI

| Anthropic | OpenAI | Notes |
|---|---|---|
| `tool_choice.type="any"` | `tool_choice="required"` | Forces at least one tool call. |
| `tool_choice.type="tool"` | Named tool object | Selects a specific tool. |
| `tool_choice.disable_parallel_tool_use` | `parallel_tool_calls` (inverted) | Enable/disable parallel tool execution. |
| Tool `input_schema` | `parameters` | The schema field name is different. |
| `thinking.type="enabled"` | `enable_thinking=true` | Enables reasoning. |
| `max_tokens` (Messages) | `max_tokens` | No difference. |
| `max_tokens_to_sample` (Completions) | `max_tokens` | Legacy naming. |

## Authentication

- OpenAI-compatible APIs use `Authorization: Bearer <api_key>`.
- Anthropic-compatible APIs use `x-api-key: <api_key>` or `Authorization: Bearer <api_key>`.
- API keys can be mapped to request priorities through server configuration.
