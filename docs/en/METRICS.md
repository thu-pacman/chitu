# Chitu Metrics

> This document is generated by `script/generate_metrics_docs.py`. Do not edit it manually; update `chitu/metrics/definitions.py` and rerun the script instead.

## Overview

Chitu exposes Prometheus metrics for debugging throughput, request latency, KV cache usage, accelerator memory, PD disaggregation, and error conditions. Raw and derived metrics are defined in a typed Python registry, and this document is generated from that registry.

## Naming and Type Notes

Python Prometheus client counter query names use a `_total` suffix. For example, `chitu_total_generated_tokens` is queried as `chitu_total_generated_tokens_total`, while `chitu_completed_requests_total` keeps that query name because it already has the suffix. Histograms expose `_bucket`, `_count`, and `_sum` series. Ratio metrics use values from 0 to 1.

## Maintenance

Update `chitu/metrics/definitions.py`, then run `python3 script/generate_metrics_docs.py`. Use `python3 script/generate_metrics_docs.py --check` in CI to verify these files are up to date. The generator only imports metric definitions and does not start Chitu, Prometheus, Grafana, model loading, or distributed runtime components.
